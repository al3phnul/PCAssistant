# profile/

This folder holds everything **specific to this machine and this user**. It is generated by the
`first-time-setup` skill (`skills/setup/first-time-setup/`) and imported automatically by `CLAUDE.md`.

| File | Contents | Written by |
|---|---|---|
| `SYSTEM.md` | OS, version, hardware, shells, package managers, init/service manager, filesystems, desktop, snapshot/rollback tools available, where `pca-*` commands are installed | Setup scan; refreshed by "re-scan" and whenever a change affects it |
| `PREFERENCES.md` | The user's answers from setup (autonomy, elevation method, package policy, communication style, rollback stack, backup repo), **Custom rules**, and **Standing duties** | Setup questionnaire; updated whenever the user changes a preference or approves a personal rule |

If these files are missing, setup hasn't been run yet — say **"First time setup"**.

These files are personal. In a shared copy of this tool they are git-ignored, so your system details never leave your machine unless you choose to back them up to your own private repo.
